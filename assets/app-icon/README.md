# Craft Fork Launcher icon

Original procedural download arrow and tray, under MIT OR Apache-2.0. No ArtCraft mark or third-party artwork is used. See ATTRIBUTION.md.

The SVG is the vector source. PNG sizes, Windows ICO and macOS ICNS are generated by packaging/fork-icons.ps1 on Windows with PowerShell 7. Generated files are committed, so ordinary builds need no renderer. packaging/icons.sh can regenerate the icon containers with resvg and the existing Rust xtask packers.

The original lowercase filenames are retained for executable and installer compatibility. The 64 px PNG is also the tray icon.
